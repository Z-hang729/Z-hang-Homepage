## Minimal inspection code

```python
from pathlib import Path
from astropy.io import fits

def summarize_fits(path):
    rows = []
    with fits.open(Path(path), mode="readonly", memmap=True) as hdus:
        for index, hdu in enumerate(hdus):
            rows.append({
                "index": index,
                "name": hdu.name,
                "hdu_type": type(hdu).__name__,
                "dimensions": tuple(hdu.header.get(f"NAXIS{i}", 0)
                                    for i in range(1, hdu.header.get("NAXIS", 0) + 1)),
                "bitpix": hdu.header.get("BITPIX"),
            })
    return rows
```

This inspects header dimensions without loading the array. FITS axes are reported in `NAXIS1, NAXIS2, ...` order; NumPy array shapes typically reverse that ordering. Binary tables require separate interpretation.

<Callout title="Preserve provenance">
Keep the original filename, source, units, observation time, and calibration history. A header summary is not a validation of scientific meaning or instrument calibration.
</Callout>
